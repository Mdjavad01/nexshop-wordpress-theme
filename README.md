# NexShop — قالب فروشگاهی وردپرس (رایگان)

> 🔥 تیره • مینیمال • کاملاً راست‌چین 🇮🇷 — برای فروشگاه‌های ایرانی و بین‌المللی

![NexShop Banner](banner.png)

## ✨ ویژگی‌ها
- ✅ پنل تنظیمات اختصاصی
- ✅ آماده اتصال به **زرین‌پال، زیبال، Stripe و PayPal**
- ✅ اتصال به **هوش مصنوعی + MCP + وب‌هوک** برای n8n و AI Agentها (REST API کاتالوگ + وب‌هوک سفارش)
- ✅ **اسکیمای سئو + تأیید گوگل و بینگ** داخل خود قالب (بدون نیاز به افزونه)
- ✅ انیمیشن‌های نرم و UI پرمیوم — تم تیره مینیمال

## 📦 نصب
1. فایل `nexshop-theme-v1.0.0.zip` را دانلود کنید (از [Releases](../../releases))
2. وردپرس → نمایش → پوسته‌ها → افزودن → بارگذاری پوسته → انتخاب فایل زیپ
3. فعال‌سازی → تنظیمات از پنل اختصاصی (نمایش → NexShop Settings)

> سازگار با **WooCommerce** — تومان/ریال + درگاه‌های ایرانی و خارجی

## 🔧 پنل تنظیمات
نمایش → NexShop Settings — لوگو، رنگ‌ها، درگاه‌ها، سئو، وب‌هوک‌ها، تأیید Search Console
